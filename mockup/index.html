Tabs (favicon) → iOS-like tab previews · + → search input · ⌃ → menu · ⚙ → settings. Edge-to-edge, no status/address bar.

Mockup notes

Arc-inspired GeckoView concept. Click around, then tell me what to change.

Tabs: favicon in navbar; tap for horizontal recents-style previews. Search (+): expands input only; queries open a DuckDuckGo results page. Menu (⌃): URL with copy, back/forward/refresh, share, extensions, settings + Mozilla pfp.
Sites: YouTube, GitHub, Gmail and Add-ons clones are long enough to scroll — page content runs edge-to-edge behind the pill, which glows while loading, condenses to a bare domain chip as you scroll down, and hands the icons back the moment you scroll up. A 3px scroll indicator fades in on the page edge.
