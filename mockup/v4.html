horiZen v4

Dark-only, mist-cyan accent, normalized stroke glyph set, frosted chrome, and a grouped sheet menu instead of the radial experiment.

dark-onlymist-cyanbackdrop-blur chromegrouped sheet menu24dp glyph grid
Chrome: the pill is 58dp, radius 29, backdrop-blur(16px) over translucency (.72 alpha), hairline top stroke. Frosted look is CSS `backdrop-filter`; the app will use PixelCopy-captured blur (noted in the research).
Grouped sheet menu: same flow as the search sheet, but purposeful clusters — Navigate (row of 5: back / forward / reload / share / pin), Tools (extensions w/ badge · downloads w/ count · find in page · translate) and System (history · settings · about). Notes area is anchored at the bottom showing the current URL, mimicking the real app’s context line.
Search + pins: flat field row (engine badge · centered input · ×), essentials row in 1.55:1 favicon-dominant tiles; hold to reorder, hold to show the red × then release to unpin; live-filtered suggestions from a built-in list.
Icons: one glyph grid — 24dp, 1.8–1.9 stroke, round caps/joins. Single-weight like the Zen set; filled accent reserved for active state.
Notable omissions: no light theme (dark-only), no grab bar, no account avatar, no pill resize on scroll (the pill is static; nav-notice shows instead).
